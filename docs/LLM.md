# LLM-модуль: объяснение кредитного решения

## Назначение
Кнопка «Объяснить простыми словами»: по уже принятому решению модель пишет клиенту
3-4 предложения - что решил банк, почему и что можно сделать дальше.

**LLM не принимает решений.** Решение формирует правиловый скоринг
(`backend/app/services/scoring.py`). Модель только пересказывает результат.

## API
`POST /applications/{id}/explain`

| Код | Значение |
|-----|----------|
| 200 | `{"text": "...", "source": "llm" \| "fallback", "model": "qwen3:4b" \| null}` |
| 404 | заявка не найдена |
| 409 | решение по заявке ещё не принято (сначала `/process`) |

`source = "fallback"` означает, что модель недоступна или не уложилась в таймаут,
и показан шаблонный текст. Основной сценарий от LLM не зависит.

## Безопасность и надёжность
- В промпт попадают только числа и коды из БД. Свободный текст пользователя (`purpose`) не передаётся,
  поэтому промпт-инъекции через заявку невозможны.
- Все расчёты (прибыль, доля платежей) делает код, не модель.
- Таймаут ответа задаётся `LLM_TIMEOUT_SECONDS` (по умолчанию 30 с), при сбое - шаблонный текст.
- Ответ кэшируется в памяти по id решения.
- Новых Python-зависимостей нет (используется стандартная библиотека).

## Запуск
Без модели (как у всех): `docker compose up --build` - эндпоинт работает в режиме fallback.

С моделью: `docker compose --profile llm up --build`.
При первом запуске сервис `ollama-pull` скачивает модель (несколько ГБ, нужен интернет). Дальше модель лежит в томе `ollamadata`.

## Переменные окружения
| Переменная | По умолчанию | Описание |
|---|---|---|
| `LLM_BASE_URL` | `http://ollama:11434` (в compose) | адрес Ollama |
| `LLM_MODEL` | `qwen3:4b` | модель с открытыми весами |
| `LLM_TIMEOUT_SECONDS` | `30` | таймаут ответа |

## Для THIRD_PARTY_NOTICES
- Ollama - сервер для запуска локальных LLM (проверить лицензию в репозитории проекта).
- Модель `qwen3:4b` (Alibaba, Qwen3) - лицензия Apache 2.0 (проверить на карточке модели перед сдачей).
- Использование: только пересказ готового решения скоринга, внешних API нет.
