# Сценарии тестирования (Test Cases)

## 1. Авторизация (JWT)
- **Шаг 1:** Вызвать `POST /auth/demo-login`.
- **Ожидаемый результат:** Код 200, возвращается `access_token` (JWT) и `token_type: bearer`.
- **Шаг 2:** Вызвать `GET /auth/me` с заголовком `Authorization: Bearer <token>`.
- **Ожидаемый результат:** Код 200, возвращается профиль демо-предпринимателя.

## 2. Создание и отправка заявки
- **Шаг 1:** Вызвать `POST /applications/` с валидными данными (ID бизнеса, ID продукта, сумма).
- **Ожидаемый результат:** Код 200, заявка создана в статусе `DRAFT`.
- **Шаг 2:** Вызвать `POST /applications/{id}/submit`.
- **Ожидаемый результат:** Заявка переходит в `SUBMITTED` и автоматически запускается обработка. В ответе возвращается обновленный статус (например, `APPROVED` или `REJECTED`).

## 3. Позитивный сценарий (Одобрение)
- **Входные данные:** Бизнес ООО "Технологии" (выручка 850 000, расходы 500 000, платежи 50 000). Запрос 1 000 000 на 36 мес.
- **Ожидаемый результат:** Скоринг выдает высокий балл. Статус заявки становится `APPROVED`.
- **Далее:** Вызвать `POST /applications/{id}/documents` -> статус `DOCUMENTS`. Вызвать `POST /applications/{id}/disburse` -> статус `DISBURSED`.

## 4. Сценарий с отказом (Негативный)
- **Входные данные:** Бизнес ООО "Риск" (выручка 300 000, расходы 290 000, платежи 180 000). Запрос 1 000 000.
- **Ожидаемый результат:** Скоринг выдает низкий балл из-за высокой долговой нагрузки. Статус становится `REJECTED`.

## 5. Проверка LLM (через API)
*(Примечание: В релизной версии UI для LLM отсутствует, проверка выполняется через Swagger/Postman).*
- **Шаг 1:** `GET /llm/status` -> ожидаем `{"available": true, "status": "ready"}` (если контейнер LLM запущен).
- **Шаг 2:** `POST /applications/{id}/explain` (для заявки в статусе APPROVED).
- **Ожидаемый результат:** Код 200, возвращается `{"text": "Текст объяснения...", "source": "llm", "model": "t-lite-it-2.1"}`.
- **Fallback-проверка:** Остановить контейнер `llm` и повторить запрос. Ожидаемый результат: `{"text": "Шаблонный текст...", "source": "fallback", "model": null}` (система не падает, основной сценарий работает).
