# Smart Credit Cabinet (Умный кредитный кабинет предпринимателя)

Веб-прототип цифрового кредитного конвейера для малого и микробизнеса (ММБ), объединяющий клиентский путь (подача заявки, отслеживание статуса, подписание) и внутреннюю банковскую логику (проверки, скоринг, принятие решения).

## 🚀 Ключевые особенности
- **Сквозной сценарий (E2E):** от создания черновика заявки до моделируемой выдачи кредита.
- **JWT-авторизация:** Безопасный доступ к API с использованием токенов. Реализован демо-вход для проверки.
- **Машина состояний:** 12 статусов заявки, включая запрос дополнительной информации, одобрение с условиями и отказ.
- **ИИ-ассистент (Бэкенд-модуль):** Генерация объяснений кредитного решения на базе локальной LLM с открытыми весами (`t-lite-it-2.1`). Работает по OpenAI-совместимому API. *(Примечание: в текущей MVP-версии модуль полностью реализован и доступен на уровне API (Swagger), однако интеграция в клиентский UI вынесена в Roadmap из-за ограничений по времени).*
- **Моки внешних систем:** Эмуляция запросов в БКИ, ЕГРЮЛ/ЕГРИП и ФНС.
- **Синтетические данные:** Готовый демо-профиль (ООО «Технологии»), 3 бизнеса, 3 продукта и предзаполненная заявка.

## 🛠️ Технологический стек
- **Backend:** Python 3.12, FastAPI, SQLAlchemy, Alembic, PostgreSQL 16, PyJWT
- **Frontend:** React (TypeScript), Vite
- **LLM (опционально):** `llama.cpp` (Docker), модель `t-tech/T-lite-it-2.1-GGUF` (Q4_K_M)
- **Инфраструктура:** Docker, Docker Compose

## 📦 Запуск проекта (Docker)
Для запуска требуется [Docker Desktop](https://www.docker.com/products/docker-desktop/).

1. Клонируйте репозиторий и перейдите в корневую папку:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd smart-credit-cabinet
   ```
2. Убедитесь, что в папке `backend` есть файл `.env` со следующими переменными:
   ```env
   JWT_SECRET_KEY=super_secret_key_for_hackathon
   DATABASE_URL=postgresql+psycopg://alfa:alfa@db:5432/credit
   ```
3. Запустите проект:
   ```bash
   docker compose up --build -d
   ```
4. Примените миграции и заполните БД синтетическими данными:
   ```bash
   docker compose exec backend uv run alembic upgrade head
   docker compose exec backend uv run python -m app.seed
   ```

**Доступы:**
- Фронтенд: `http://localhost:5173`
- Swagger UI (API): `http://localhost:8000/docs`

## 🧪 Сценарий проверки (E2E)
1. Откройте `http://localhost:5173`.
2. Нажмите «Подробнее» и затем «Войти через демо-пользователя» (вызовется `POST /auth/demo-login`, токен сохранится в LocalStorage).
3. На главной странице выберите кредитный продукт (например, «Экспресс-кредит») и создайте заявку.
4. Отправьте заявку на рассмотрение.
5. Перейдите в раздел «Очередь банка» (или используйте Swagger `POST /applications/{id}/process`), чтобы запустить автоматическую обработку (валидация -> проверки -> скоринг -> решение).
6. Вернитесь в клиентский интерфейс. Если заявка одобрена — подпишите документы (моделирование).
7. Совершите выдачу кредита (моделирование перевода средств).

### 🧠 Проверка LLM (ИИ-ассистент)
Так как LLM не интегрирована в UI, её можно проверить через Swagger:
1. Запустите контейнер с моделью: `docker compose --profile llm up --build -d` (скачает ~5 ГБ).
2. В Swagger выполните `GET /llm/status` (дождитесь статуса `ready`).
3. Выполните `POST /applications/{id}/explain` для любой заявки, по которой уже принято решение. API вернет текстовое объяснение от модели (или fallback-текст, если она недоступна).
