## Artificial Intelligence (LLM)
- **T-lite-it-2.1** (T-Technologies / T-Bank) — языковая модель с открытыми весами (Open Weights).
  - Лицензия: Apache 2.0.
  - Формат: GGUF (`t-tech/T-lite-it-2.1-GGUF`).
  - Использование: генерация текстовых объяснений кредитных решений (исключительно на основе фактов из БД). В релизной версии модуль доступен на уровне API (Swagger).
- **llama.cpp** (MIT License) — движок для инференса LLM на CPU (образ `ghcr.io/ggml-org/llama.cpp:server`).
- **Hugging Face** — внешний сервис, используемый *только* для первичной загрузки весов модели. В проверяемой версии решения отсутствует зависимость от платных API.

## Смоделированные интеграции (Mocks)
В соответствии с условиями кейса, реальные интеграции с внешними системами заменены моками:
- **БКИ (Бюро кредитных историй):** Имитация запроса кредитной истории.
- **ЕГРЮЛ / ЕГРИП:** Имитация проверки статуса компании.
- **ФНС (Прозрачный бизнес):** Имитация проверки налоговых нарушений.

*Примечание: Реальные запросы к перечисленным государственным и банковским системам не выполняются. Все данные (клиенты, бизнесы, заявки) являются синтетическими.*
